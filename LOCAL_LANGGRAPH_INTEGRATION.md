## Error Handling

If the local LangGraph server is unavailable, the system will return:

```json
{
  "error": "Local LangGraph server unavailable",
  "message": "Connection refused",
  "suggestion": "Ensure your local LangGraph server is running at http://localhost:8000"
}
```

**No fallback to mock responses** - this ensures you always get real AI-generated output from your local server.

## Configuration

### Local LangGraph Server Requirements

Your local LangGraph server at `http://localhost:8000` should:

1. **Accept POST requests** at `/api/generate` endpoint
2. **Accept JSON body** with:
   ```json
   {
     "request": "User's question/request",
     "metrics": {}, // Channel metrics (optional)
     "recentVideos": [], // Recent video data (optional)
     "taskType": "creator_coach",
     "userId": "user-id" // Optional
   }
   ```
3. **Return JSON response** with the AI-generated coaching advice
